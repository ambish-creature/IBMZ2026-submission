IBMZ2026 third-party resources and direct URLs
==============================================

This is a declaration of external packages, pretrained models, data, services,
and infrastructure referenced or used by this repository. Project Python code
is team-authored; the links below are not copied source code. requirements.txt
is the installable package list. This file is for attribution, not pip install.

PRETRAINED MODELS AND DATA
Current image model (downloaded at runtime on the VM):
https://huggingface.co/delpot/steganograph-ia-detector

MAGE text dataset (download commands in main.ipynb; dataset files are not in Git):
https://huggingface.co/datasets/yaful/MAGE
https://huggingface.co/datasets/yaful/MAGE/resolve/main/train.csv
https://huggingface.co/datasets/yaful/MAGE/resolve/main/valid.csv
https://huggingface.co/datasets/yaful/MAGE/resolve/main/test.csv

Earlier image model evaluated, not used by the current application:
https://huggingface.co/buildborderless/CommunityForensics-DeepfakeDet-ViT
